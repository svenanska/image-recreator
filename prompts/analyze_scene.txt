GOAL

Create the most accurate possible image reconstruction blueprint for GPT Image 2 and other image generation models.

The purpose is NOT to describe the image.

OUTPUT FORMAT

Output ONLY valid JSON.

No commentary.

FORBIDDEN INFERENCE RULE
